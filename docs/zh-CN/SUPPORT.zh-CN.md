# 支持政策

[English](../../SUPPORT.md) | 简体中文

单维护者、尽力维护的开源项目，只支持 npm 最新版本。不承诺响应／修复／发布日期或长期版本支持。

## 用户与产品范围

面向配置第三方 API 的个人开发者。ccset 编辑本地文件并提供已实现的[选择／会话命令](user-guide.zh-CN.md#cli)；保存不会修改已有会话。不管理 Provider 账户、计费、可用性，不认证 API 兼容性。

不保证恢复丢失凭据／配置、接纳所有提案、及时修复未验证平台，或兼容未成文／已变化的上游行为。ccset 导致的数据丢失／凭据暴露优先级最高，但不承诺时限。

## 平台

| 层级 | 环境 |
| --- | --- |
| 支持 | macOS、Linux |
| 尽力支持 | WSL、Windows Terminal 配 PowerShell |
| 不支持 | `cmd.exe`、移动终端、普通终端使用之外的特殊 WSL 集成 |

WSL 的 POSIX `0600` 适用于 Linux 文件系统，不适用于挂载的 Windows 文件系统。原生 Windows 不管理 ACL，需自行检查 Agent 与备份目录权限。发布证据注明具体 Agent／Node／OS／终端／shell 版本，不代表任意组合。

## 维护状态

暂时无活动不等于放弃。维护停止时仓库会明确说明，并保持开放以供可信社区维护者提出接管。
